# Claude Code Guide - Project Overview

## Purpose
A static website guide for Claude Code CLI, featuring tips, tricks, hidden features, and productivity hacks. Published on GitHub Pages.

## Tech Stack
- **HTML5** - Structure
- **CSS3** - Styling with CSS custom properties (variables)
- **Vanilla JavaScript** - Interactivity (no frameworks)
- **GitHub Pages** - Hosting

## Project Structure
```
claudecode-guide/
├── index.html      # Main HTML with all accordion sections
├── styles.css      # All styles (dark terminal theme)
├── app.js          # Search, navigation menu, accordion logic
├── README.md       # Project documentation
└── .gitignore      # Git ignore rules
```
